NFS Most Wanted - Sun Set

Installation:
1. Install TexWizard.
2. Drop everything from SunSet folder to the game root.
Merge packs in TexWizard.json if needed.
3. (Optional) Install DXVK.

If you are expiriencing issues with NextGenGraphics then use NextGenGraphics.MostUnWanted by Sh2dow.

Features:
- Full day/night time cycle.
- Custom world and car shaders.
- Enhanced road reflections.
- Car rain effects.
- Dynamic ligting.
- Improved motion blur.
