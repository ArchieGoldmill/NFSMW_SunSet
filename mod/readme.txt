NFS Most Wanted - Sun Set 1.9

Installation:
1. Install TexWizard (https://github.com/R-033/texwizard/releases/tag/1.2).
2. Drop everything from SunSet folder to the game root.
   Merge packs in TexWizard.json if needed.
3. (Optional) Install DXVK (https://github.com/doitsujin/dxvk/tags).

Features:
- Full day/night time cycle.
- Custom world and car shaders.
- Enhanced road reflections.
- Car rain effects.
- Dynamic ligting.
- New motion blur effect.
